# REACH: Research Evaluation & Analytics Capacity Hub

REACH is a global community of research administrators, analysts, librarians and
researchers working on research analytics and responsible research assessment.
This organization holds the code and data our members publish openly, so that
someone facing a familiar problem can start from work that's already been done.

**Browse everything at [research-analytics-hub.github.io](https://research-analytics-hub.github.io).**
Each listing there links to its repository, names the people who maintain it, and
shows when it last changed.

## Sharing your work

If you've published code, data or a guide that would save another research
analytics team some time, we'd like to list it. You can keep the repository
wherever it lives now; it doesn't need to move into this organization.

- [Request a listing](https://github.com/research-analytics-hub/research-analytics-hub.github.io/issues/new?template=resource-request.yml)
  by filling in a short form, and a REACH reviewer will write it up for you.
- [Open a pull request](https://github.com/research-analytics-hub/research-analytics-hub.github.io/blob/main/CONTRIBUTING.md)
  with the listing yourself, if you're comfortable editing a text file on GitHub.

## More from REACH

The [REACH website](https://reach.uky.edu/) covers the rest of the community's
work, including the Research Analytics Mentorship Program and virtual events.
